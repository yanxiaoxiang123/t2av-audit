# T2AV 实际检查与证据规则

以下规则保留原项目的审核边界，并将旧项目入口替换为本 Skill 的工具。以实际送入生成模型的 Prompt 为准。通用音频事件未列出时须定向复核；仍不确定，不确认缺失。

【评分依据与边界】

    1. 以本任务文档内嵌的指标定义、条件启用规则、常见错误及逐指标 0–5 分锚点为唯一评分标准。执行前完整阅读本节和文末评分表。
    2. 7 个通用指标必须逐项评估并给出 0–5 分：VQ、AE、VF、AQ、AF、AV、TS。通用指标没有“无法判断”或“不适用”状态；能力限制、局部不可辨认和检查限制写入 uncertainty 或 inspection_limits，不影响选择最符合现有证据的锚点。
    3. 10 个条件指标：DC、LS、TX、PH、MU、PR、SB、HM、MT、PS。仅在 Prompt 明确涉及时启用并给出 0–5 分；Prompt 未涉及对应要求时标记“不适用”，score=null，并给出 Prompt 范围及不适用原因。不得因为生成结果缺失本应出现的内容而改标“不适用”。
    4. LS：画外音不标口型同步。TX：仅要求服装存在文字或 Logo、未指定具体文字内容、拼写或出现时机时，TX=不适用，外观在 VF 判断。条件启用需引用 实际模型输入 Prompt 原文，不得套用其他样本的指标列表。
    5. 已评分项只允许 0、1、2、3、4、5 六个整数，严格匹配该指标的原始锚点；不得自创百分制、加减分公式、同步毫秒阈值、权重或总分算法。本任务评分标准未给出明确总分公式，本任务仅输出逐指标得分，overall_score=null。
    6. “不适用”只用于 Prompt 未涉及的条件指标；0 分是经核实达到零分锚点。指标评分不使用“无法判断”。工具解码失败不等于源视频损坏，工具不能听音不等于视频无音轨；这些情况写入检查限制，并按其他实际证据与疑罪从无原则选择锚点。
    7. 采用疑罪从无原则：评分只依据实际确认的缺陷，不把可能存在但未证实的问题当作错误。完成覆盖全片的合理检查后，未发现可确认缺陷时，应按无确认缺陷对应的锚点评分；疑似运动模糊、遮挡或细节变化若无法与正常拍摄现象区分，不扣分，也不得仅因此标记无法判断。所有分数（包括 3–5 分）仍须给出评分理由、对应锚点及正向覆盖证据。0–2 分必须填写明确失败原因。不能依据画面美观推断物理、声音或指令遵循正确。
    8. 本任务评分标准未明确且影响打分的情况（如无任何可验证声音事件时的 AV）记录具体限制，仍按已有事实和疑罪从无原则选择最符合的 0–5 分锚点，不扩展条件指标的“不适用”范围。

【实际检查方法】

    1. 检查媒体可访问性，记录真实元数据：视频时长、帧尺寸、帧率、可变帧率情况、音轨有无、采样率与声道数。未知字段填写 null 并说明。
    2. 确认能实际读取并目视检查视频帧。音频使用本 Skill 的 analyze_audio.py 本次调用 Gemini 生成的云端分析证据，明确标注模型与结果路径；audio_available=false 或调用失败时停止声音内容判断。不得将旧报告、ASR、自动检测器或其他模型结论冒充 当前审核模型 本次直接观察。
    3. 将 Prompt 拆为可验证要求：主体、数量、属性、场景、机位、动作、顺序、结尾、对白、声效、环境声、音乐、声源及时间关系。保存原文片段，映射涉及的指标。
    4. 尽可能正常速度完整观看，结合本次 Gemini 原音轨分析建立事件时间线；随后按时间顺序复查全片。分别记录实际观看、人工听取、云端音频分析和抽帧覆盖范围，不能只检查开头、中间、结尾；不得将云端音频分析记为 当前审核模型 正常速度听取。
    5. 若只能抽帧，第一轮至少每秒 4 帧覆盖全片；接触、遮挡、交接、快速运动、切镜、口型及音画同步片段至少每秒 12 帧，受源帧率限制时检查所有可用原始帧，不插值凑帧。仍不明确时查看原始连续帧。局部问题使用原分辨率裁剪放大，不依赖缩略接触表下结论。
    6. 连续动作须检查发生前、发生中、发生后，重点核验手物接触、穿模、人体结构、物体消失或跳变、物理因果、步骤及最终状态。静态结构须检查交界处；不得用臆测的开孔、固定件或遮挡解释可疑相交。
    7. 音频由 Gemini 处理本次原始音轨；关键片段证据不足时可再次调用 analyze_audio.py --start/--end/--focus 分析原音频片段，记录片段与源时间的映射。对白按模型实际识别内容核对，听不清的词标记无法辨认，禁止用 Prompt 补全。ASR、波形、频谱只能辅助定位，不能单独证明语义、音色、情绪或材质声音正确。
    8. AV/LS/SB 等联合指标核对同一时间轴上的画面与音频；逐事件记录声音和视觉起点、峰值、终点中实际可确定的项目。偏移定义为 audio_time_sec - visual_time_sec，正值表示声音滞后；无法测量时填 null，不虚报毫秒精度。
    9. 使用原始媒体呈现时间戳（PTS）进行帧与声音对齐，记录时间基准及音视频起始偏移。帧号从 0 开始；可变帧率不得用 frame_index/fps 冒充真实时间。音频证据保持原声道和可追踪时间映射，不降噪、合成或改变速度后冒充原音频。
    10. 复查所有影响评分的关键片段，并记录确认事实、疑似问题、遮挡/不可辨认及工具限制。未观察到的内容不能写成已确认事实；未证实的疑点也不能写成缺陷、据此扣分或拒绝为指标选择锚点。

【强制证据要求】

    1. 每个数值评分至少引用一条已验证的证据记录；证据数量由覆盖需求决定。全局质量和满分结论需要覆盖全片的检查记录及分布于相关时间段的代表证据，单个好帧不能证明全片优良；已完成合理的全片抽帧覆盖时，不得仅因没有正常速度播放或未做穷尽式局部复核而拒绝评分。
    2. 对有可解码画面的每个数值评分，保存关联原始证据帧和标注帧，记录时间戳、原始帧号、宽高及实际路径。正向证据也要标注目标区域；全局构图/质量可以框选全帧，但必须标为 global，不得冒充局部定位。
    3. 局部视觉证据必须给出实际可见对象和位置框，包含主体/对象名称、框的作用、局部观察。交互或穿模应同时标注交互双方及关键接触区域；口型框选嘴部，文字框选实际文字区域。
    4. bbox_xyxy 使用原始呈现帧像素坐标 [left, top, right, bottom]，原点左上，右/下边界不包含在框内；必须满足 0 <= left < right <= width、0 <= top < bottom <= height。保存旋转处理及裁剪坐标映射。标注图须保持原帧尺寸；裁剪图另外保存，不能拿裁剪/缩放坐标冒充原图坐标。
    5. 所有框须在实际目视帧后确定并在标注图复核，不能凭 Prompt、物体通常位置、模型未验证建议或固定坐标生成。红框标异常，绿框标满足要求的区域，文字标签写 evidence_id 和对象。不得修改原始画面来增强、重建或制造证据。
    6. 连续动作、闪烁、结构跳变、步骤与同步问题须保存前/中/后帧或覆盖事件的连续帧序列，并说明变化过程；单帧不能独立证明运动、同步或因果。必要时同时保存原始片段。
    7. AQ/AF/DC/MU/PR/MT 及所有依赖听觉的评分必须引用实际导出的音频片段，记录源时间区间、声道、听到的事实及播放核验结果。配套视频帧仅用于时间定位，不能代替音频证据。
    8. 纯音频、画外声、配乐或看不到声源时，配套帧标记为 temporal_context，boxes=[]，并填写 bbox_unavailable_reason；禁止虚构声源位置。只有实际可见且已确认的关联对象才画声源框。波形/频谱图不能充当视频对象框。
    9. 缺失类结论必须记录应出现的 Prompt 要求、完整搜索/复听范围、代表帧或音频片段。不存在的对象不能画“对象框”；全帧可标为搜索范围，并明确其不是对象定位。稀疏抽帧无法排除短暂出现时，应保留不确定性。
    10. 若源文件经验证确实无音轨或无可解码画面，保存真实探测/解码日志，引用其作为缺失证据；仅在本任务评分标准对应锚点明确适用时给分。无法产生的帧、音频或框填 null/空数组并说明物理上不存在，不伪造替代品。
    11. 区分证据客观不存在与工具未能提取。声音证据可来自本次成功的 Gemini 原音轨分析；不能仅因 当前审核模型 未亲自听取而否定该证据。所有通用指标以及已启用的条件指标都必须按已有事实和疑罪从无原则选择 0–5 分锚点。未正常速度播放、未做穷尽式复核、局部遮挡、能力限制或潜在遗漏只记录在 uncertainty 或 inspection_limits，不得令指标 score=null，也不得使用“无法判断”作为指标状态。
    12. 所有证据文件必须先实际保存并重新打开核验后才能引用。重复使用同一证据可引用同一 evidence_id，但须分别解释对不同指标的支持。不要重复列举同一缺陷凑数或机械重复扣分。
